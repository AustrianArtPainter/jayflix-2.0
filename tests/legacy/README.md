# Legacy parity fixtures

Frozen from Jayflix commit `140740efeb9374c51b8c2ef3a6166557d6ca96ef` before
independent Jayflix 2.0 publication. Source: https://github.com/AustrianArtPainter/Jayflix.

These four files are test-only baselines for exact sphere mathematics, palette
values, responsive header rules and built-in source identities. They are not
served or imported by the production app. Copying them into this repository keeps
the original parity tests executable in an independent checkout without changing
the old repository or weakening compatibility assertions.

The legacy baseline retains its Apache-2.0 license in this directory; the new app
and its upgraded foundation retain the AGPL-3.0-or-later license at repository root.
